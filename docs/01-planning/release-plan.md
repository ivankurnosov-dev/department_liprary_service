# Сетевой график и вероятностный прогноз релиза

В состав MVP вошли истории: 1, 10, 2, 3, 4.

## 1. Сетевой график и критический путь
Зависимости историй:
* ID 1 (Добавление книги) и ID 10 (Авторизация) могут выполняться параллельно на старте.
* ID 2 (Поиск) требует готовой структуры из ID 1.
* ID 3 (Бронирование) требует логики поиска из ID 2.
* ID 4 (Выдача) требует механизма бронирования из ID 3.

Анализ путей:

Путь 1: Старт → ID 10 → Финиш = 5.33 ч.

Путь 2 (Критический): Старт → ID 1 → ID 2 → ID 3 → ID 4 → Финиш = 2.17 + 4.33 + 4.33 + 2.17 = 13.0 часов.

Вывод: Критический путь составляет 13 рабочих часов. История 10 имеет резерв времени (13.0 - 5.33 = 7.67 часов) и не влияет на общую длительность проекта.

## 2. Вероятность завершения MVP (PERT)
Требуется оценить вероятность завершения работы к дате защиты ЛР 3 (через 3 недели).

Доступное время (T): 18 рабочих часов (с учетом коэффициента фокуса).

Ожидаемое время критического пути (E): 13.0 часов.

Дисперсия критического пути: Сумма дисперсий историй 1, 2, 3 и 4 = 0.25 + 1.0 + 1.0 + 0.25 = 2.5.

Стандартное отклонение пути (SD): √2.5 ≈ 1.58 ч.

Расчет Z-индекса:
Z = (T - E) / SD = (18 - 13) / 1.58 = 3.16.
Вероятность, соответствующая Z = 3.16 по таблице нормального распределения, составляет > 99.9%.
Мы с уверенностью успеваем выполнить MVP в срок.

## 3. Прогноз методом Монте-Карло
Поскольку исторических данных команды пока нет, используется симуляция пропускной способности от 1 до 4 историй в неделю (согласно заданию). Размер MVP — 5 историй.

По результатам 10 000 симуляций (аналог работы скрипта monte_carlo.py):

С вероятностью 50%: MVP будет завершен за 2 недели.

С вероятностью 85%: MVP будет завершен за 3 недели.

Прогноз подтверждает, что выделенных 3 недель достаточно для завершения всех 5 задач MVP даже при пессимистичном развитии событий.
